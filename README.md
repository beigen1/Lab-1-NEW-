This project is a simple 2D scene created in Godot using a space theme. The main scene includes a space background along with a spaceship and alien sprites placed within the environment. To complete the requirement of using nested scenes, I created a separate scene containing a single alien sprite and then instanced it multiple times into the main scene. This allowed me to reuse the same object instead of duplicating it manually, which helped me better understand how scene instancing works in Godot.

One thing I learned during this project was how important it is to properly set the main scene in the project settings so the game runs correctly. I also learned how positioning and scaling affect what appears when the scene is played, especially since objects can be off screen if they are not centered.

A challenge I ran into was figuring out how to correctly instance a scene into the main scene. At first, I had all the pieces but they were not connected properly. After redoing the process, I now understand how to create a separate scene and bring it into another scene as a reusable object.

Overall, this project helped me get more comfortable with Godot’s scene system, organizing nodes, and working with sprites in a 2D environment.
